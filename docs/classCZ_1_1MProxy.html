Detailed Description

template<class T>
class CZ::MProxy< T >

A Wayland proxy of type T, with the registry name of the global it was bound from.

Converts implicitly to T*, so it can be passed directly to the protocol functions. Holds a null proxy (and name 0) when unset. It doesn't own the proxy: destroying it doesn't destroy the Wayland object.
