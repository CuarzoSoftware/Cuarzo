Detailed Description

Text that can be selected and, optionally, edited.

The core of text input: no background, border or padding (wrap it in other nodes for that), just the text, its selection highlight and a blinking caret. Use it to show text the user can select and copy (selectable(), the default), or edit (setEditable()).

Layout

The node is sized to its text. With a wrap width (setWrapWidth()) it's that wide and the text wraps (lines aligned with setTextAlign()); otherwise it's as wide as the longest line. Lines are only broken at \n while editing a single-line editor (see setMultiline()). setMaxLines() ellipsizes long text while it's not being edited.

Interaction

  • Pointer: click to place the caret, drag to select (Shift+click extends), double click selects a word (dragging extends by words), triple click selects everything.
  • Keyboard: arrows (Ctrl: by words, Shift: extending the selection), Home/End (Ctrl: whole text), Ctrl+A, Ctrl+C. Editable: typing, Backspace/Delete (Ctrl: by words), Ctrl+X, Ctrl+V, Ctrl+Z / Ctrl+Shift+Z (or Ctrl+Y). Enter emits onSubmit (multiline: inserts a line break, Ctrl+Enter submits) and Escape emits onCancel.
  • It takes keyboard focus when clicked, and drops it when a press lands outside it (emitting onEditingFinished).

Copy & paste use AKApp::clipboard() (unavailable without one).

Positions (selection, caret) are byte offsets into text() (UTF-8), always at code point boundaries.
