Registers the animation in CZCore and subscribes the optional callbacks to onUpdate and onFinish.

A CZCore must exist. If oneshot is true, the animation is deleted by CZCore after it finishes or is paused.

◆ reset()

virtual void reset ( )
virtualnoexcept

Restarts the animation from the beginning, even if it is already running.

Resets the timeline and the value to its start (via onStart(): 0 for CZLinearAnimation, the from point for CZSpringAnimation) and keeps it running. Useful to re-trigger a transition after its endpoints changed, from the current intermediate state, without waiting for it to finish.

◆ pause()

void pause ( )
noexcept

Pauses the animation.

Stops the animation immediately without invoking the onFinish callback. The current state is preserved and will remain unchanged until start() is called again.

◆ advance()

virtual void advance ( )
protectedpure virtualnoexcept

Advances the animation state for the current frame.

Called by CZCore on each step while running. Implementations update m_value and set m_isRunning to false when the animation has finished.

Implemented in CZLinearAnimation, and CZSpringAnimation.

Emitted on every animation step, after the value has been updated. Carries this animation.

Subscribe with onUpdate.subscribe(owner, callback). A callback may also be passed to the constructor (it is subscribed here with the animation itself as the owner).
