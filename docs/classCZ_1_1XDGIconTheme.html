Detailed Description

An icon theme.

This class encapsulates the properties and data of an icon theme, including its name, directories, fallback themes, and associated metadata.

Icon themes are loaded lazily. The loading typically occurs whenever XDGIconThemeManager::findIcon() attempts to access iconDirectories() or scaledIconDirectories() for the first time.

◆ CacheMagicV2

std::string_view CacheMagicV2 { "\0XDGKIT2", 8 }
staticconstexpr

First bytes of a v2 cache file (written by the indexer).

v2 stores each directory's icons sorted by name, with an offset table, so they're looked up in the mapped file instead of being loaded into memory. A v1 file starts with the theme name (never empty), so the leading NUL tells them apart.
