Detailed Description

Shared sd-bus (D-Bus) connection integrated into the CZCore event loop.

There is at most one system and one user bus connection per process. They are created on demand by GetOrMakeSystem() / GetOrMakeUser() and kept alive only while someone holds the returned std::shared_ptr. Incoming messages are dispatched from the event loop through eventSource(), and CZCore takes timeoutMS() into account when waiting for events.

Use bus() with the sd-bus API to make calls, add matches, etc.

void processQueued ( )
noexcept

Processes messages sd-bus already read but didn't dispatch.

A blocking call (e.g. sd_bus_call_method()) reads every message that arrives while it waits into an internal queue. The socket is then empty, so the event source isn't woken for them. CZCore calls this after each dispatch.
