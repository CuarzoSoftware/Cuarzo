Detailed Description

A vertical list of menu rows (MMenuItem) with a macOS-style selection outline.

Reusable inside any surface: an MMenu, an MTooltip, ... Add items by parenting them to the view. Dividers at the very top or bottom are hidden automatically.

Member Function Documentation

◆ activate()

void activate ( MMenuItem * item)
noexcept

Activates item like a click: its highlight blinks a few times (like macOS), then its onClicked runs and onItemActivated is emitted.

Hovering other items does nothing meanwhile. Safe if the menu goes away during the blink.
