Detailed Description

Entry point of the library: loads icons and images, in-process or through the service.

ABCore is a singleton, created with GetOrMake() after the CZCore (the connection to the service and the cache use its event loop) and the RCore (images are Ream images).

In remote mode icons are looked up and rasterized by the service: the app doesn't load icon themes (no XDGKit) nor parse SVGs, and images are imported from DMA-bufs shared with every other app. In local mode the same is done in-process.

Every image is for a DRM device (Ream's main device by default) and shared: while some copy of it is alive, requesting it again returns the same image. Once the last copy is destroyed it's kept for a grace period (see setGracePeriod()), so momentarily dropped images (e.g. rebuilt menus) are not generated again. After that it's released (in remote mode, the service's reference is dropped; the service frees it once no app uses it).

Not thread-safe: use it from the thread of the CZCore.

◆ IconProvider()

static ImageProvider IconProvider ( const ABIconKey & key,
RDevice * device = nullptr,
std::optional< ABShadow > shadow = std::nullopt )
staticnoexcept

For AKImageFrame::setImageProvider(): key at the size it's drawn at.

For each pixel size and scale, looks up the icon with size = ceil(pixelSize / scale) and that scale (the theme may have artwork made for it) and fits it in a pixelSize square.

With a shadow, the image is the pixelSize square with the icon and its shadow: the icon is smaller, the shadow's padding is ABShadow::PaddingFor(pixelSize, shadow->radius) (the padding given is ignored). The frame should then extend past the icon's area by radius times the icon size on each side.
