Louvre

Overview

Library for building Wayland compositors.

Header#include <CZ/Louvre/LCompositor.h>
pkg-configcz-louvre
Mesondependency('cz-louvre')
Depends onCore, Ream, SRM, Skia

Louvre uses the factory method pattern to provide default implementations for all major functionality and protocols, which you override gradually: a compositor works from day one and you customize it class by class. It handles the DRM and Wayland backends, input through libinput, buffer management, explicit synchronization, fractional scaling, multi-GPU setups and around forty Wayland protocols.

Main Classes

  • LCompositor is the entry point; override its createObjectRequest() to return your own subclasses of the factory objects (LFactoryObject).
  • LSurface, LToplevelRole, LPopupRole, LLayerRole and the other roles represent client windows.
  • LOutput is a display, LSeat with LPointer, LKeyboard and LTouch handles input, and LClient is a connected client.
