Detailed Description

The Flexbox (Yoga) layout of a node.

Each AKNode owns an AKLayout, accessible via AKNode::layout(), which wraps a Yoga node. The setters and getters map 1:1 to the Yoga YGNodeStyleSet* / YGNodeStyleGet* functions, and each setter that dirties the Yoga node automatically flags the owner with AKNode::CHLayout so it is re-laid out and repainted on the next AKScene::render().

The scene calculates the layout during AKScene::render(). The calculated results (position and size) are then available through AKNode::worldRect() or the calculated...() getters, the latter being relative to the parent node.

◆ setAnchorNode()

void setAnchorNode ( AKNode * anchor)
noexcept

Sets an anchor node for this node.

Makes this node’s position relative to the specified anchor node instead of its parent, while preserving the current hierarchy.

While an anchor is set, the position type is forced to YGPositionTypeAbsolute. The previous position type is restored when the anchor is unset.

If the anchor node is destroyed, it is automatically unset.

Parameters

◆ calculate() [1/2]

void calculate ( )
noexcept

Calculates the node layout.

If the node has a parent, YGNodeCalculateLayout is called using the parent node and the already calculated width and height.

If the node does not have a parent, YGNodeCalculateLayout is called from the node itself with YGUndefined for both width and height.

Note
This only updates the calculated...() values of the layout, which are always relative to the parent node. Properties such as AKNode::worldRect() or AKNode::sceneRect() are only updated from AKScene::render().
