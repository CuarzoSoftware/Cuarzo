Detailed Description

Runs blocking D-Bus work off the main thread.

A single background thread runs the jobs in order, each given that thread's own bus connection (sd-bus connections can't be shared between threads). A job returns what to do next on the main thread (e.g. apply the values it read), run from the CZCore event loop.

CZBusWorker worker { CZBusWorker::System };
worker.run([](sd_bus *bus) -> std::function<void()> {
int enabled {};
sd_bus_get_property_trivial(bus, "org.freedesktop.NetworkManager", ..., 'b', &enabled);
return [enabled]{ updateUI(enabled); }; // Main thread
});

Jobs run on another thread: they must not touch the owner's state (copy what they need), their completions may. Destroying the worker waits for the running job and drops the pending ones and their completions.
