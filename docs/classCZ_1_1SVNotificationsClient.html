Detailed Description

The client side of desktop notifications (user bus): sending them, and controlling Gazette (Cuarzo's notifications daemon). See SVNotificationsServer for the other side.

Sending works with any daemon implementing the Desktop Notifications Specification (org.freedesktop.Notifications). onActionInvoked and onClosed are emitted for the notifications sent from here only.

Gazette's state (whether it runs, its notification center, Do Not Disturb) is tracked over org.cuarzo.Gazette, onChanged tells when it changed.

Shared by the process: see GetOrMake().

auto notifications { SVNotificationsClient::GetOrMake() };
SVNotification n;
n.summary = "Download complete";
n.body = "photo.png";
n.actions = { { "default", "Open" } };
notifications->send(n);
notifications->onActionInvoked.subscribe(this, [](UInt32 id, const std::string &action){ ... });
