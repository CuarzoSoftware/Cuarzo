Building

The Cuarzo repository builds every library and application of the framework together, with versions known to work with each other. The libraries are Meson subprojects in subprojects/.

Yoga

Yoga 3.2.1 (used by Kay) isn't packaged by these distributions; build and install it from source:

$ git clone --branch v3.2.1 --depth 1 https://github.com/facebook/yoga.git
$ cd yoga
$ cmake -S . -B build -DCMAKE_BUILD_TYPE=Release -DBUILD_SHARED_LIBS=ON
$ cmake --build build -j $(nproc)
$ sudo cmake --install build

Build and install

$ git clone --recurse-submodules https://github.com/CuarzoSoftware/Cuarzo.git
$ cd Cuarzo
$ meson setup builddir -Dbuildtype=release --wrap-mode=forcefallback
$ cd builddir
$ meson compile -j $(nproc)
$ sudo meson install

Subprojects can be left out with their with_* options (see meson_options.txt), e.g. -Dwith_qtcuarzo=false. Enabling a library also enables the libraries it depends on.

This documentation

The documentation is generated with Doxygen (and Graphviz for the diagrams) from the headers of every library:

$ meson compile -C builddir docs # Output in builddir/docs/html

or, without a build directory:

$ doxygen/gen-docs.sh # Output in docs/html
