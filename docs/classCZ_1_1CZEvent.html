enum class Type
strong

Event types.

The *_First and *_Last values delimit the input, pointer, keyboard and touch ranges (see isInputEvent(), isPointerEvent(), etc.). Custom event types should start at User.

◆ isAccepted()

bool isAccepted ( ) const
inlinenoexcept

Whether the event was accepted.

CZCore::sendEvent() marks events as accepted before dispatching them. Receivers can call ignore() to reject an event (e.g. to refuse a CZCloseEvent), which the sender can check here.
