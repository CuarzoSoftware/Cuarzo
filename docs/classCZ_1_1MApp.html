Detailed Description

The Marco application: connects to the Wayland compositor and runs the event loop.

There is a single instance, created with Make() and retrieved anywhere with Get(). Make() sets up everything a Kay app needs on Wayland: the CZCore event loop, the Ream graphics core (on the Wayland display), the AKApp (Kay) instance and the default MTheme. It then connects to the compositor and binds its globals (see wl); it fails if a required one (wl_compositor, wl_shm, wl_seat with a pointer, xdg_wm_base, wp_viewporter, cursor-shape-v1) is missing.

After creating the app, create surfaces (MToplevel, MLayerSurface, ...) with their Kay node trees and call run():

#include <CZ/Marco/MApp.h>
#include <CZ/Marco/Roles/MToplevel.h>
using namespace CZ;
int main()
{
auto app { MApp::Make() };
app->setAppId("org.example.hello");
MToplevel window;
window.setTitle("Hello");
window.setMapped(true);
return app->run();
}

◆ colorScheme()

CZColorScheme colorScheme ( ) const
inlinenoexcept

The system color scheme, applied to every surface (and its nodes).

Follows the desktop's preference (the XDG desktop portal's org.freedesktop.appearance color-scheme setting, e.g. GNOME's org.gnome.desktop.interface color-scheme), Light if unavailable. Changes are applied live and notified through onColorSchemeChanged.
