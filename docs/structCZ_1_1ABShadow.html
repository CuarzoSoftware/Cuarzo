Detailed Description

A drop shadow drawn under an icon or image (optional, see ABCore::icon()).

Icons shown over pictures or busy backgrounds (desktop icons, dock tiles...) usually get a soft shadow following their shape. Drawn by the asset broker, the icon and its shadow are one image, shared by every app like any other asset (no live blur when the app repaints).

The image keeps the requested box: the icon is fitted in the box minus padding on each side (centered, at a whole pixel offset so it stays sharp), and the shadow fills that room. The shadow's blur and offset are fractions of the icon's size, so it keeps its look at any size.

// A 64 px icon in a 94 px image: 15 px of room on each side for its shadow
CZ::ABShadow shadow { .padding = 15, .radius = 15.f / 64.f, .offsetY = 2.f / 64.f, .color = 0x66000000 };
auto image { ab->icon(key, { 94, 94 }, nullptr, &shadow) };

The padding of an image pixels wide/tall with an icon whose shadow needs margin (a fraction of the icon size) on each side.

The icon is floor(pixels / (1 + 2 * margin)) pixels and the padding half of what's left (rounded down). Used by ABCore::IconProvider() with radius as the margin.
