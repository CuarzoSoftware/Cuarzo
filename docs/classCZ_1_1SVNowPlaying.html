Detailed Description

What's playing (MPRIS media players: Spotify, browsers, video players...), e.g. for a Now Playing card.

The player shown is the one playing, else the last one that did (or any). Its artwork is a local file or downloaded once to $XDG_CACHE_HOME/cz-services/artwork/ (players like Spotify give URLs). Kept up to date from the players' D-Bus signals; reads and commands run off the UI thread.

Shared by the process: see GetOrMake().
