Detailed Description

Built-in generators of shared assets.

A generator draws an image from the parameters of an ABGenKey. They are built into the library (and so into the service), so apps and the service draw exactly the same thing. Names include a version: a generator whose output changes gets a new name, so a service from another version never hands out a different image (unknown generators are drawn in-process, see ABCore::generate()).

The ak.* generators are Kay's default theme assets (see AKTheme). Sizes are in logical pixels; images are size * scale pixels.
