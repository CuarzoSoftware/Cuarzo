◆ RenderNodeId()

dev_t RenderNodeId ( dev_t dev)
noexcept

Device id of the render node of the GPU with device id dev.

The same GPU can be reported by its primary node (/dev/dri/cardN) or its render node (/dev/dri/renderDN). Comparing the ids returned by this function tells whether two device ids refer to the same GPU. Returns dev itself if it has no render node.

◆ OpenRenderNodes()

std::vector< int > OpenRenderNodes ( )
noexcept

Opens the render node of every GPU (O_RDWR | O_CLOEXEC).

For headless processes (the service, tests) that create an RCore with an RDRMPlatformHandle: render nodes don't need DRM master and are enough to allocate GBM buffers.

◆ MakeHeadlessRCore()

std::shared_ptr< RCore > MakeHeadlessRCore ( )
noexcept

Creates an RCore for a headless process, with every GPU's render node.

Uses the DRM platform (GL unless CZ_REAM_GAPI says otherwise) without DRM master, so no scanout, but GBM buffers can be allocated and shared. nullptr on failure.

◆ FindIconFile()

std::filesystem::path FindIconFile ( XDGKit & kit,
const ABIconKey & key )
noexcept

The file of the first icon of key found (see XDGIconThemeManager::findIcon()).

The Icon of the .desktop entry of key.appId (if any) is tried first. Names that are absolute paths are used as is if the file exists. When an icon has both, the SVG is preferred (if accepted by key's extensions). Empty if none is found.
