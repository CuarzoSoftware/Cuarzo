Detailed Description

Background blur controller for surfaces.

This class allows configuring the background blur effect for a surface and listening to client changes. See LSurface::backgroundBlur().

Clients request it through one of two protocols (a surface uses at most one of them):

  • lvr_background_blur (Louvre's): blur state, region, color scheme, clipping masks and, since version 2, the material (blur radius, saturation and tint, see Props::material) and the effect's opacity (Props::opacity).
    1. The configureRequest() is triggered, typically before the surface is mapped.
    2. The compositor configures the blur state.
    3. The client specifies the region to blur and may optionally apply an additional clipping mask.
    4. The client acknowledges and commits the changes, which are notified via propsChanged().
  • ext_background_effect_v1 (standard): only a blur region, no color scheme or masks. There is no configure/acknowledge handshake: configureRequest() is triggered when the client creates the object, and the state set with configureState() is applied right away (notified via propsChanged()). A client removing the effect sets an empty region (the state is unchanged).

In both cases the blur is shown while visible(): the compositor enabled it and the region isn't empty. See backgroundBlurResource() and backgroundEffectResource().

The final blur region is determined by the intersection of the surface bounds, the region(), and the optional clipping mask.

The compositor can modify the state and color hint configuration at any time but should always wait for the client’s acknowledgment before applying the changes.

Compositors may support different masking capabilities depending on their rendering features. Modify MaskCaps to advertise the supported capabilities to clients.

Note
Both globals are created by default in LCompositor::createGlobalsRequest() (except with the Raster graphics API). Compositors that don't render background blur should remove them, so clients don't rely on it (e.g. making their windows translucent).

State state { Disabled } The current blur state.
CZColorScheme colorScheme { CZColorScheme::Unknown } The current blur color hint.
MaskType maskType { NoMask } The current mask type.
SkRegion region { SkRegion() } Region in local surface coordinates to be blurred.

It is guaranteed that the region does not extend beyond the surface bounds.

CZRRect roundRectMask Returns the current rounded rectangle mask, if the mask type is set to RoundRect .

The rounded rectangle is guaranteed to be valid, but it may extend beyond the surface bounds.

If the compositor does not support rounded rectangle masks, it should remove the RoundRectMaskCap from MaskCaps to prevent clients from using it.

SkPath svgPathMask Returns the current SVG path mask, if the mask type is set to SVGPath .

Note that the path may extend beyond the surface bounds.

Warning
Louvre does not validate the SVG commands within the string. It is the responsibility of the caller to ensure the SVG path is valid.

If the compositor does not support SVG path masks, it should remove the SVGPathMaskCap from MaskCaps to prevent clients from using it.

optional< Material > material The material requested by the client, or std::nullopt to let the compositor choose.

Always std::nullopt with ext_background_effect_v1 and lvr_background_blur version 1. The values are validated (non-negative) but not clamped.

Float32 opacity { 1.f } Opacity of the whole effect requested by the client, in [0, 1].

Clients fade it along with their content (lvr_background_blur version 2). Always 1 with ext_background_effect_v1 and lvr_background_blur version 1.

UInt32 serial { 0 } Returns the last acknowledged configuration serial.
bool isEmpty { true } Indicates whether the blur region is empty.

Equivalent to region().empty().

bool isFullSize { false } Indicates whether the blur region covers the entire surface.

Returns true if region() contains a single rectangle matching the current surface bounds.

◆ configureState()

void configureState ( State state)
noexcept

Sets the blur state.

The configuration is immediately stored in pendingConfiguration().

  • lvr_background_blur: asynchronous. The client is notified and the current state is kept until it acknowledges the change (notified via propsChanged()).
  • ext_background_effect_v1: no handshake, the state is applied right away (propsChanged() is called from here if it changed).

If blur is not supported() calling this function is a no-op.

◆ configureRequest()

virtual void configureRequest ( )
virtual

Triggered when the client creates a background blur resource for the surface.

Either protocol (see backgroundBlurResource() and backgroundEffectResource()). The compositor should respond by configuring both the blur state and color hint. If no configuration is explicitly sent, Louvre will automatically apply the current pending configuration values, which default to Disabled for the state and Unknown for the color hint.

Default implementation

void LBackgroundBlur::configureRequest()
{
configureState(Enabled);
}
