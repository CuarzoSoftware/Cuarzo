Detailed Description

Base class for objects.

Provides the features shared by all Cuarzo objects:

  • Signal subscriptions: an object can own CZSignal subscriptions (see CZSignal::subscribe()), which are removed automatically when it is destroyed.
  • Weak references: CZWeak references to the object are set to nullptr when it is destroyed.
  • Events: events sent to the object through CZCore::sendEvent() are first passed to its installed event filters (see installEventFilter()) and then to event().

Objects can't be copied or moved.

◆ installEventFilter()

void installEventFilter ( CZObject * monitor) const
noexcept

Installs monitor as an event filter of this object.

Events sent to this object through CZCore::sendEvent() are first passed to the eventFilter() of its monitors, most recently installed first. If a filter returns true, the event is not delivered further. Installing an already installed monitor moves it to the front. The filter is removed automatically when either object is destroyed.

◆ notifyDestruction()

void notifyDestruction ( )
protectednoexcept

Notifies the object destruction.

This method can be invoked from a subclass destructor to notify the object's imminent destruction to all associated CZWeak references in advance. If not invoked, the base CZObject automatically calls it.

After invocation, all CZWeak references are set to nullptr, preventing the creation of additional references for this object.
