Detailed Description

template<class T>
class CZ::CZBitset< T >

Compact way of storing and managing conditions or states.

The CZBitset class template is similar to std::bitset in that it enables the compact storage of a set of conditions or states using bits.
Unlike std::bitset, CZBitset functions are designed to modify and retrieve bit states using flags rather than indices, which are ideally defined within an enum.

It is widely used in the private API of AK classes to optimize memory usage.

Example usage:

enum MyFlags
{
FlagA = 1 << 0,
FlagB = 1 << 1,
FlagC = 1 << 2
};
CZBitset<MyFlags> myFlags;
myFlags.add(MyFlags::FlagA | MyFlags::FlagC);
if (myFlags.check(MyFlags::FlagC))
{
// do something
}
