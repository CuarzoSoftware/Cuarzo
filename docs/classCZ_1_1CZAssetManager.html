Detailed Description

template<typename T, typename... Args>
class CZ::CZAssetManager< T, Args >

Generic cacheable asset factory.

Creates assets of type T through a factory function and caches them by their creation arguments (Args). The cache only holds weak references: an asset is shared while someone keeps a std::shared_ptr to it, and recreated by the factory once all references are gone. Expired cache entries are purged periodically on get().
