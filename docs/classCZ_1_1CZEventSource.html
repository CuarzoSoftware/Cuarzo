Detailed Description

File descriptor monitored by the CZCore event loop.

Registers a file descriptor in the CZCore epoll instance and invokes a callback from CZCore::dispatch() whenever any of the requested events occur.

The source stays registered while the user holds the std::shared_ptr returned by Make(). Once the last user reference is released, the callback is no longer invoked and the fd is removed from the event loop (and closed if it was created with CZOwn::Own).
