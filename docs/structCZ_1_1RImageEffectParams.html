inlinestaticnoexcept

UV bounds the effect taps are mirrored at: validRect (or dst) intersected with dst, mapped by uvMatrix (see RMatrixUtils::VirtualToUV()) and inset by 1.5 texels.

In a downscaled image the edges may fall mid-texel, leaving the outermost texel partially invalid. A bilinear fetch at the bound reads the texels whose centers surround it, so the bound must be at least 1.5 texels inside for both to be fully valid (1 isn't enough when the edge is less than half a texel into the outermost one).

◆ tapStep

Float32 tapStep { 1.f }

Distance between blur taps, in texels of the image (whatever src and scales). Scales the blur sigma at no cost; keep it within ~[0.75, 1.5] to avoid visible banding.

VibrancyV only: affine color transform applied after the blur, row-major 3x4: ‘r’ = m[0]r + m[1]g + m[2]b + m[3]` (and so on for g and b), clamped to [0, 1]. Saturation, tint and brightness all fold into it (see MakeVibrancyMatrix()).

◆ validRect

std::optional<SkRect> validRect

Area holding valid image content, in the same coordinates as RDrawImageInfo::dst (it maps to src the same way), or std::nullopt for the whole dst.

Taps falling outside it are mirrored back into it (each axis independently, so corners are mirrored both ways), so the blur never reads invalid texels: e.g. the part of src beyond a screen edge (never captured), or outside src.
