Detailed Description

The service side: rasterizes assets on behalf of clients and shares them as DMA-bufs.

Listens on ABProtocol::SocketPath() (see ABProtocol for the messages). Only processes of the same user are accepted.

Icons are looked up here (LoadIcon), with the service's own XDGKit, so apps don't need one. Themes are reloaded when the indexer updates their cache (checked at most every 5 s).

Assets are cached by file, size and device, and shared by every client. Each client's references are counted; an asset no client references is kept for a grace period ($CZ_ASSET_BROKER_SERVER_GRACE_MS, 10000 by default) and then released. Memory is actually freed once no process has it imported either.

Requires a CZCore and an RCore whose devices can allocate GBM buffers (e.g. GL on render nodes, see ABUtils::OpenRenderNodes()).
