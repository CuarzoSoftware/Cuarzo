Detailed Description

Gets images from the cz-asset-broker service, imported from DMA-bufs.

Requests are synchronous (the reply is waited for, with a timeout of CZ_ASSET_BROKER_TIMEOUT_MS, 2000 by default). The DMA-buf fds are closed once imported.

Each image holds a reference in the service, released (in batches, on the next event loop iteration) when the image's Result::keepAlive is destroyed. All of them are released if the connection closes, but already imported images stay valid.
