Detailed Description

The system clipboard (text), as provided by the windowing layer.

Kay doesn't talk to the windowing system itself: the toolkit built on it (e.g. Marco, with Wayland's data device) sets an implementation with AKApp::setClipboard(). Without one, AKApp::clipboard() is nullptr and nodes don't offer copy & paste.
