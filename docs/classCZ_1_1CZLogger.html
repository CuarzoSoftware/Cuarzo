Detailed Description

Leveled logger with std::format style formatting.

Messages are printed as <namespace> <Level>: <context><message>, to stderr for CZFatal and CZError and to stdout for the rest. Messages above the logger level are discarded.

CZLogger log { "MyApp", "MY_APP_LOG_LEVEL" };
log(CZInfo, "Loaded {} items", count);
log(CZError, CZLN, "Failed to open {}", path); // Also prints the file and line
