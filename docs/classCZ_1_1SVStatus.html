Detailed Description

The system status for a bar's indicators: network, volume and battery.

Each is exposed as a freedesktop symbolic icon name (empty = nothing to show, e.g. no battery):

  • Network: NetworkManager (system bus). The Wi-Fi signal strength of the active wireless connection, otherwise wired, otherwise Wi-Fi offline/disabled. Hidden without NetworkManager or network devices.
  • Volume: the default output's, from SVAudio (shared with the rest of the process). Muted, low, medium or high.
  • Battery: UPower's display device (system bus), its level in steps of 10 %, and charging / charged / plugged in; and its warning level (batteryWarning), for low battery notifications.

Everything is event driven (D-Bus signals, SVAudio's changes), onChanged is emitted when the state changes. The queries run off the UI thread (see CZBusWorker).

Shared by the process: see GetOrMake().
