Heaven

Overview

Global menus for Wayland sessions over D-Bus.

Headers#include <CZ/Heaven/Bar/HNBar.h>
#include <CZ/Heaven/Client/HNClient.h>
#include <CZ/Heaven/Compositor/HNCompositor.h>
pkg-configcz-heaven-bar, cz-heaven-client, cz-heaven-compositor
Mesondependency('cz-heaven-client') (etc.)
Depends onCore

Heaven lets Wayland clients export their application menus to a single global menu application (the bar), and lets the compositor decide whose menu is shown. The objects and their properties are mirrored on both ends over the D-Bus session bus.

Heaven is three independent libraries, one for each side:

Library Used by Role
Heaven Bar The global menu application Receives and mirrors the menus of every client; delivers clicks back.
Heaven Client Applications Publishes the app's menu tree and reacts to clicks.
Heaven Compositor The compositor Authenticates clients and tells the bar which one is active.
