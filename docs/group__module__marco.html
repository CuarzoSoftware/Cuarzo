Marco

Overview

Library for building Wayland applications with Kay.

Header#include <CZ/Marco/MApp.h>
pkg-configcz-marco
Mesondependency('cz-marco')
Depends onCore, Ream, Kay, XDGKit, Skia

Marco connects to the Wayland compositor, creates the Ream context and gives each surface a Kay scene, so windows, popups and panels are built with Kay nodes.

Main Classes

  • MApp is the application; MScreen represents an output.
  • Surface roles: MToplevel (windows), MDialog (dialogs attached to a window), MPopup and MMenu, MTooltip, MSubsurface, MLayerSurface (wlr_layer_shell panels and backgrounds) and MSessionLockSurface.
  • Nodes: MVibrancyView (blurred backgrounds), MSidebar (a resizable window sidebar with the window buttons), MPopUpButton (a drop-down list opening an MMenu) and the menu items (MMenuView, MMenuAction).
  • Extensions for desktop components: foreign toplevel management (MForeignToplevelManager), output management (MOutputManager) and session locking.
