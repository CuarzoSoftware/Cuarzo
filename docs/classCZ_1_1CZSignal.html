Detailed Description

template<class... Args>
class CZ::CZSignal< Args >

Notifies subscribed callbacks with arguments of types Args.

Callbacks are subscribed with subscribe(), each owned by a CZObject: when the owner is destroyed, its subscriptions are removed automatically, so callbacks never run on a destroyed owner.

CZSignal<int> onValueChanged;
onValueChanged.subscribe(this, [](int value) {
// ...
});
onValueChanged.notify(5);
