XDGKit

Overview

Utilities for the XDG specifications: icon themes, desktop entries, MIME types and the trash.

Header#include <CZ/XDG/XDGKit.h>
pkg-configcz-xdgkit
Mesondependency('cz-xdgkit')
Depends onCore

XDGKit finds icons following the XDG Icon Theme Specification, using caches generated by cz-xdgkit-icon-theme-indexer for fast lookups. It doesn't load icons: it returns their paths, sizes and formats. It also reads desktop entries, the MIME database and the trash.

Main Classes

  • XDGKit is the entry point; XDGIconThemeManager finds a XDGIcon by name, size, scale and theme.
  • XDGDesktopEntry, XDGMimeDatabase and XDGTrash.
  • Helper functions in the XDGUtils namespace.
