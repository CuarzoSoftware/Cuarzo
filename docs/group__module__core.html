Core

Overview

Core classes and utilities shared by every Cuarzo library: objects, signals, events, timers, animations and logging.

Header#include <CZ/Core/CZCore.h>
pkg-configcz-core
Mesondependency('cz-core')
Depends onSkia

Core is the foundation of the framework. It provides the main event loop (CZCore), the object model every other library builds on (CZObject, CZSignal, CZWeak, CZOwn), the input and window events delivered to applications and compositors, timers, animations and the logger.

Main Classes

  • Event loop: CZCore drives timers, file descriptor event sources (CZEventSource) and queued events. Applications create it once with CZCore::GetOrMake().
  • Objects and signals: CZObject, CZSignal and CZListener for callbacks; CZWeak references that become nullptr when their object is destroyed.
  • Events: input (pointer, keyboard, touch and gesture events), layout, window state, color scheme and presentation events, all deriving from CZEvent.
  • Animations: CZAnimation, CZLinearAnimation and CZSpringAnimation.
  • Utilities: CZTransform, CZRRect, CZBitset, CZSpFd, shared memory, string, math and region helpers.
