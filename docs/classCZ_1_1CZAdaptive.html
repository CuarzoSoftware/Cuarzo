Detailed Description

template<class T>
class CZ::CZAdaptive< T >

A value with distinct light and dark appearances.

Holds two values of type T and resolves to one of them based on a CZColorScheme, mirroring macOS / SwiftUI dynamic system colors. Trivial and constexpr (when T is), so it can be used as a compile-time constant (e.g. the named colors in AKTheme).

See also
CZAdaptiveColor, the CZAdaptive<SkColor> alias (declared in Cuarzo.h).
