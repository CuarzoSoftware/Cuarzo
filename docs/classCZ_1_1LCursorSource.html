◆ Visibility

enum Visibility

Cursor visibility modes.

Defines how a source affects the LCursor visibility when applied. Used by cursor sources from clients that may carry visibility information.

Enumerator
Hidden 

The cursor is hidden when applied, regardless of the LCursor state.

Visible 

The cursor is made visible when applied, regardless of the LCursor state.

Auto 

The cursor preserves the current LCursor visibility state when applied.
