Detailed Description

Lists the outputs (displays) and changes how they're set up (wlr-output-management).

Accessed through MApp::ext. Only works if MOutputManagerExt was passed to MApp::Make() and the compositor supports the protocol (available() is false otherwise, and heads() stays empty).

Each output is an MOutputHead, enabled or not, with the modes it supports (MOutputMode). Changes the compositor sends are applied atomically: each new head is announced with onAdded, changed ones emit MOutputHead::onPropsChanged, and then onChanged is emitted. The initial state usually arrives during MApp::Make() (before anything can subscribe), so read heads() right after it.

To change the setup, pass the new configuration of the heads that change to apply() (the others keep theirs). The compositor applies all of it or nothing:

MOptions options;
options.extensions.add(MOutputManagerExt);
auto app { MApp::Make(options) };
// The heads are known by now (later changes: onChanged)
auto &manager { app->ext.outputManager };
MOutputHead *head { manager.heads().front() };
MOutputHead::Config config { head->config() };
config.scale = 2.0;
manager.apply({ { head, config } }, [](MOutputManager::Result result) {
// ...
});

◆ apply()

bool apply ( const std::unordered_map< MOutputHead *, MOutputHead::Config > & configs,
std::function< void(Result)> done = {} )
noexcept

Asks the compositor to set the outputs up as configs says.

Heads not in configs keep their current configuration (MOutputHead::config()). done is called once with the result, unless the app quits first. Like the props, the new state arrives later through MOutputHead::onPropsChanged and onChanged.

Returns
false (and done isn't called) if not available() or no heads are known yet.
