The Cuarzo Framework

The Cuarzo Framework
C++ libraries for building Linux desktops: Wayland compositors, Wayland applications and the components of a desktop session (panels, docks, menus, lock screens). They share one core and one graphics stack, so they can be used together or on their own.

Modules

Core
Event loop, objects and signals, input events, timers, animations and logging shared by every library.

cz-core

Ream
GPU buffer allocation, DMA-buf sharing between devices and a portable painter over OpenGL ES, Vulkan and raster.

Architecture

Each module depends only on the modules below it. Compositors are built with Louvre, applications with Marco and Kay.

Using the libraries

Each library installs a pkg-config file and its headers under <prefix>/include/CZ. Headers are included by their path, e.g. #include <CZ/Louvre/LCompositor.h>, and every class lives in the CZ namespace.

With Meson:

cz_louvre_dep = dependency('cz-louvre')
executable('my-compositor', 'main.cpp', dependencies: cz_louvre_dep)

Or with pkg-config directly:

$ g++ -std=c++20 main.cpp $(pkg-config --cflags --libs cz-marco) -o my-app

See Building to build and install the framework, and Environment Variables for the environment variables the libraries read.
