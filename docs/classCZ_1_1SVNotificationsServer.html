Detailed Description

The server side of desktop notifications (user bus), for a notifications daemon.

Implements the protocol and leaves showing the notifications to the daemon, through Handlers:

  • org.freedesktop.Notifications at /org/freedesktop/Notifications (the Desktop Notifications Specification 1.2): Notify (its arguments and hints read into an SVNotification), CloseNotification, GetCapabilities, GetServerInformation, and the NotificationClosed / ActionInvoked signals (emitClosed(), emitActionInvoked()). Hints read: urgency, desktop-entry, image-data (and the older image_data and icon_data), image-path (and image_path), transient and resident.
  • Optionally, the notification center's org.cuarzo.Gazette at /org/cuarzo/Gazette (what SVNotificationsClient controls): ToggleCenter(s screen), ShowCenter(s screen), HideCenter(), SetDoNotDisturb(b), GetState() → (b centerShown, b doNotDisturb, u count, s screen), and the StateChanged(bbus) signal (emitCenterState()).
SVNotificationsServer::Handlers handlers;
handlers.notify = [](const SVNotification &n) -> UInt32 { return show(n); }; // Its id
handlers.close = [](UInt32 id){ remove(id, SVNotification::CloseReason::Closed); };
server = SVNotificationsServer::GetOrMake();
server->start(handlers, { .name = "My Daemon", .vendor = "Me", .version = "1.0" });
