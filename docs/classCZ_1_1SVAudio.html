Detailed Description

The audio devices (through pactl, so PipeWire or PulseAudio): choosing the default output and input (and which of their channels), their volume, the input level and playing sounds.

Commands run off the UI thread; onChanged tells when state() changed (watched with pactl subscribe, so changes from anywhere show up).

Some channels of a device (e.g. outputs 3+4 of a multichannel interface, or one input of it) are used through a virtual device routing to them (module-remap-sink/source), made the default one. There's one per direction, shared by every app: the state shows the device and the channels, not the virtual device. The channels chosen are remembered ($XDG_CONFIG_HOME/cz-services/audio-channels) and restoreChannels() recreates them in a new session.

Shared by the process: see GetOrMake().
