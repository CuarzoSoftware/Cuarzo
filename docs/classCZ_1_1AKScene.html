Detailed Description

Renders a tree of nodes into AKTargets.

A scene calculates the layout of its node tree, tracks damage and renders the nodes back-to-front into a given target during render(). It also behaves like a window from the input point of view: it keeps the pointer and keyboard focus and dispatches input events to the right nodes (see Event System).

Applications typically use one scene with a single target per window, while compositors can share one scene across multiple targets (e.g. one per screen). See Core Components.

Member Function Documentation

◆ render()

bool render ( std::shared_ptr< AKTarget > target)
noexcept

Renders the node tree into the given target.

Calculates the layout (unless AKTarget::layoutOnRender is disabled), dispatches bake/render events, performs damage tracking and fills the target's output regions.

Returns
false if the target is invalid (e.g. missing surface or root node).

◆ setRoot()

Root node.

Only the children of the root node are rendered. The root node's bounds do not clip its children, but its layout properties may affect them.
