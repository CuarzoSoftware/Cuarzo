Kay

Overview

GPU-accelerated GUI toolkit: a scene of nodes laid out with Yoga and drawn with Skia or Ream.

Header#include <CZ/AK/AKScene.h>
pkg-configcz-kay
Mesondependency('cz-kay')
Depends onCore, Ream, AssetBroker, Skia, Yoga

Kay builds user interfaces from trees of nodes. Scenes track damage so only changed regions are drawn again, support fractional scaling and screen transforms, and can be embedded in Wayland clients (through Marco) or in compositors.

Main Classes

  • AKScene is a node tree; AKTarget defines how and where it's drawn.
  • AKNode is the base of every node: AKContainer only lays out its children, AKRenderable draws directly, AKBakeable draws into a cached image and AKSubScene renders its children into its own image.
  • Ready to use components (buttons, text fields, scroll views, images...) and background effects such as shadows and blur.

Guides: Core Components, Creating Components and Event System.
