Detailed Description

The default Marco theme: AKTheme plus client-side decoration (CSD) parameters and assets.

Installed by MApp::Make(); get it with MApp::theme(). Subclass it to customize the CSD look.

virtualnoexcept

Generates (and caches) a drop-shadow frame for a rounded-rect window.

The image is a shadow "frame" with a transparent centre, sized to innerSize plus the margins implied by radius / offsetX / offsetY. When innerSize is large enough a minimal clampable image is returned and sides reports which axes may be 9-slice stretched; otherwise the shadow is rendered at full size and sides is cleared.
