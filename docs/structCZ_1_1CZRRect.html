Detailed Description

Integer rectangle with a radius for each corner.

Extends SkIRect with corner radii, ordered clockwise from the top-left corner.

bool isValid ( ) const
inlinenoexcept

Whether the rectangle and radii are consistent.

The size and radii must be non-negative, and the radii of adjacent corners must not add up to more than the width or height of the side they share.
