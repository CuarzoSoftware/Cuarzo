Detailed Description

Turns image files (SVG and the raster formats Skia decodes) into RImages.

Parsed SVG documents are kept while any image rendered from them is alive (see Result::keepAlive), so rendering the same SVG at another size skips reading and parsing it again.

Used by ABLocalBackend and by the service (ABServer).
