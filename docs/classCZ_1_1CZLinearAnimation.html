Detailed Description

Time-based animation utility.

This class provides a mechanism for animating object properties such as position, color, opacity, and more. It runs for a fixed duration, specified in milliseconds.

Once started, the onUpdate() callback is invoked periodically, allowing access to the value() property, a 64-bit floating-point number linearly interpolated from 0.0 to 1.0 representing the animation's progress.

When the animation completes, the onFinish() callback is triggered. At that point, value() will return 1.0.
