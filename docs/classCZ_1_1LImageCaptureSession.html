Detailed Description

A client capturing an output or a toplevel.

Created when a client starts an ext-image-copy-capture session. It starts pending: LImageCaptureManager::sessionRequest() decides, possibly later, whether to accept() or stop() it. Once accepted, the client receives the buffer constraints (bufferSize(), formats) and can request frames (see LImageCaptureFrame).

Changes are tracked as damage, in buffer coordinates: each frame carries (and copies) only what changed since the client's previous frame. The first frame is always complete.

Cursor sessions (isCursorSession()) capture the cursor image instead, and the client gets the cursor's position over the source separately (handled by Louvre).

The session is destroyed by its client (see LImageCaptureManager::sessionDestroyed()). It's stopped when its source (output or toplevel) is destroyed.

◆ isCursorSession()

bool isCursorSession ( ) const
inlinenoexcept

Whether it captures the cursor image (a cursor session).

Its frames are the cursor image, at the scale of the source (its buffer size follows the cursor size), sent again when the image changes. Louvre also tells the client where the cursor is over the source (enter, leave, position and hotspot), while accepted.

◆ setBufferSize()

void setBufferSize ( SkISize size)
noexcept

Changes the size of the frames.

Useful when rendering toplevel frames yourself (see LToplevelRole::imageCaptureFrameRequest()) with a different size, e.g. including server-side decorations. The client receives the new constraints, the current frame fails (it must reallocate its buffers) and the next one is complete.

◆ addDamage()

void addDamage ( const SkRegion & region)
noexcept

Marks a region as changed, in buffer coordinates.

Louvre tracks the damage of outputs and toplevel surfaces itself. Use this for changes it can't know about, e.g. the server-side decorations of a captured toplevel. A frame waiting for changes is then captured.
