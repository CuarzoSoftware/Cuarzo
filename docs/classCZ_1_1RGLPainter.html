Detailed Description

OpenGL backend implementation of RPainter.

Executes the painter's draw operations using hand-written GLSL programs (RGLProgram/RGLShader) selected by feature flags, rendering into the framebuffer of the pass's surface image. Created internally by RGLDevice; obtained from a pass via RPass::getPainter().

Draws an image onto the surface.

This function renders an image onto the target RSurface, clipped to a specified region.

  • If no mask is provided, the effective rendering area is the intersection between region and image.dst.
  • If a mask is provided, the region is further intersected with mask.dst.
Parameters

◆ MarkSkiaGLStateDirty()

static void MarkSkiaGLStateDirty ( )
staticnoexcept

Marks the current thread's GL state as dirtied by Skia.

Skia (SkCanvas) draws leave GL state the painter doesn't rebind on every draw (stencil, color mask, etc.) in an undefined configuration. Passes call this whenever a canvas is used so the next painter draw on this thread re-syncs the state first — including draws from a DIFFERENT pass (e.g. an asset baked with Skia in the middle of another pass's painter rendering, which would otherwise silently discard the following draws).
