Detailed Description

Lists the windows of other clients (wlr-foreign-toplevel-management).

Accessed through MApp::ext. Only works if MForeignToplevelManagerExt was passed to MApp::Make() and the compositor supports the protocol; otherwise the list stays empty.

MOptions options;
options.extensions.add(MForeignToplevelManagerExt);
auto app { MApp::Make(options) };
app->ext.foreignToplevelManager.onAdded.subscribe(this, [](MForeignToplevel *toplevel) {
// ...
});
