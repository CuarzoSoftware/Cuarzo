Detailed Description

A window of another client (wlr-foreign-toplevel-management), e.g. for docks and taskbars.

Listed by MForeignToplevelManager (MApp::ext, requires MForeignToplevelManagerExt). Created and destroyed by the manager: it's announced with MForeignToplevelManager::onAdded once its initial props are known, and destroyed right after MForeignToplevelManager::onRemoved.

◆ captureImage()

bool captureImage ( std::function< void(std::shared_ptr< RImage > image)> done)
noexcept

Captures an image of the window (e.g. a thumbnail of a minimized window).

Uses ext-image-copy-capture with a source created (ext-image-capture-source) from this toplevel's ext-foreign-toplevel-list handle, found through props().identifier (sent by Louvre's wlr-foreign-toplevel v4). Its size is up to the compositor (Crystals sends docks a small version of the window, with its title bar). The compositor may also ask the user first.

done is called once, with the image or nullptr (failed, denied, or the window is gone), unless this object is destroyed first.

Returns
false (and done isn't called) if the compositor doesn't support it.
