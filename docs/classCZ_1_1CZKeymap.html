Detailed Description

XKB keymap and keyboard state.

Wraps an xkb_context, xkb_keymap and xkb_state, plus an optional compose table/state (loaded from the LC_ALL, LC_CTYPE or LANG locale, falling back to "C"). Key events passed to feed() are translated into keysyms and UTF-8 text, and the modifiers state is tracked.

  • Server keymaps (MakeServer()) compute their own state from key presses and expose the keymap string through a read-only fd() / size() pair that can be shared with Wayland clients.
  • Client keymaps (MakeClient()) are built from a keymap received from a server, and their modifiers are set by the server through updateModifiers().

The current keymap used by the process is held by CZCore (see CZCore::keymap()).
