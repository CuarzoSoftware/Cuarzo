Detailed Description

Vulkan RSync backed by a DRM syncobj timeline.

NVIDIA's Vulkan does not support exporting/importing semaphores as sync_file (SYNC_FD) — only OPAQUE_FD, which for timeline semaphores on Linux aliases a drm_syncobj. Minting the fd straight from a SYNC_FD semaphore silently failed on NVIDIA and broke synchronization, so the durable representation is a drm_syncobj timeline point instead:

  • Make(): import the syncobj into a Vulkan timeline semaphore via OPAQUE_FD, then an empty submit signals it to the point after all prior queue work (the GPU signal materializes the syncobj point).
  • fd(): export a sync_file from the syncobj point (DRM ioctl — driver-agnostic, works on NVIDIA).
  • FromExternal(): import a sync_file into a fresh syncobj point (DRM ioctl).

If the device lacks the Timeline capability, it degrades to a SYNC_FD semaphore (m_fd), or to an already-signaled no-op if that is unavailable too.
