Detailed Description

File type detection and default applications (shared-mime-info and mimeapps.list).

Types are detected from file names (the shared-mime-info globs2 files), with a few fallbacks for names no glob matches: directories, empty files and plain text. Content sniffing (magic) isn't supported.

Default applications follow the XDG MIME Applications spec: mimeapps.list files (defaults and added/removed associations), then the mimeinfo.cache of each applications directory, then the type's parents (e.g. text/x-csrc falls back to text/plain).

The databases are loaded on first use. Get it from XDGKit::mimeDatabase().
