Ream

Overview

Graphics library for Linux: GPU buffer allocation, DMA-buf sharing between devices and a portable painter.

Header#include <CZ/Ream/RCore.h>
pkg-configcz-ream
Mesondependency('cz-ream')
Depends onCore, Skia

Ream abstracts the platform (DRM, Wayland, offscreen) and the graphics API (OpenGL ES 2.0, Vulkan, raster) behind one API. It allocates GPU buffers (native, GBM/DMA-buf or dumb buffers), shares them across devices on hybrid GPU systems, synchronizes them with explicit sync_file fences and draws into them with a built-in painter or with Skia.

Main Classes

  • RCore initializes Ream for a platform and graphics API; get it anywhere with RCore::Get().
  • RDevice represents a GPU. RImage is an image that can be shared across devices, RSurface wraps an image to draw into, and RPainter draws into it.
  • Portable code uses the classes directly under CZ/Ream; API-specific implementations live in CZ/Ream/GL, CZ/Ream/VK and CZ/Ream/RS (reached with e.g. image->asGL()).

See 🧩 Abstraction for how the platform and API abstraction works.

noexcept

Returns Ream's shared logger.

The logger is created lazily on first use and is named "Ream". Its verbosity is controlled by the CZ_REAM_LOG_LEVEL environment variable.

Returns
A reference to the process-wide Ream logger.
