Detailed Description

An icon to look up: the parameters of XDGIconThemeManager::findIcon().

In remote mode the lookup is done by the service, so the app doesn't need an XDGKit.

Member Data Documentation

◆ names

std::vector<std::string> names

Icon names in order of preference (the first one found is used).

findIcon()'s icon, with fallbacks. Absolute paths are accepted too (e.g. the Icon key of some .desktop files).

◆ appId

std::string appId

App whose icon this is (optional).

If set, the Icon of the app's .desktop entry is tried before names (which can then hold fallbacks, e.g. the app id itself and generic app icons).
