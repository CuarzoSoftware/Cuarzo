Detailed Description

DRM/KMS resource lease.

Represents a temporary delegation of connectors, CRTCs, and planes to another process. Created via SRMDevice::createLease(). The lease is revoked and the fd closed on destruction. Leased resources cannot be used by SRM until revoked.
