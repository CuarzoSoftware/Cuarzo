Detailed Description

NetworkManager's Wi-Fi (system bus): its state, joining and forgetting networks.

Everything is read and done off the UI thread (see CZBusWorker); onChanged tells when state() changed. Without NetworkManager (or a Wi-Fi device) state().available is false.

Shared by the process: see GetOrMake().

void scan ( )

Asks the device to look for networks (e.g. while a list of networks is shown).

While it's on and no network is listed (e.g. right after turning it on, when the device isn't ready to scan yet), it's asked again every few seconds until some show up.
