Detailed Description

An exported toplevel (xdg-foreign zxdg_exported_v1 / zxdg_exported_v2).

Shared by RXdgExportedV1 and RXdgExportedV2. Exporting gives the client a secret, unguessable handle it can pass to another client, which imports it (RXdgImportedBase) to make its own toplevels children of the exported one (e.g. a portal dialog over the app that opened it).

The handle stays valid until this object or its toplevel is destroyed. Then every import of it receives its destroyed event, and later imports of the handle are invalid.

An export without a toplevel (a v1 export of a surface without the xdg_toplevel role, for which v1 defines no protocol error) is inert: it has no handle and can't be imported.
