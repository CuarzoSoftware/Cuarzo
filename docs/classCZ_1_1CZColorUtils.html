static constexpr bool IsColorDark ( SkColor c,
Float32 threshold = 0.5f )
inlinestaticconstexprnoexcept

Whether c is perceptually dark (Rec. 601 luma below threshold).

threshold defaults to the 0.5 midpoint. Ignores alpha. Callers that decide a contrasting foreground may raise it so mid-luminance fills (e.g. saturated greens) are treated as dark.
