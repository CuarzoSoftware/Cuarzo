Detailed Description

Image capture sessions (screenshots, screen recording and sharing)

Clients capture outputs and toplevels through the ext-image-copy-capture protocol, choosing what to capture with ext-image-capture-source. Each capture is an LImageCaptureSession, which delivers frames (LImageCaptureFrame) to the client.

Capturing is a privacy matter, so every new session must be accepted first: sessionRequest() is called and the session stays pending, without producing frames, until LImageCaptureSession::accept() or LImageCaptureSession::stop() is called. This can happen at any later time, e.g. after asking the user with a modal dialog. The default implementation accepts every session right away.

Once accepted, everything is handled by Louvre:

  • Outputs: frames are copied from the output images after each paintGL(), only when something changed and only the changed regions (with or without the cursor, as the client asks).
  • Toplevels: frames are rendered by LToplevelRole::imageCaptureFrameRequest() when its surfaces are damaged. The default implementation draws the toplevel's surface and subsurfaces; override it to e.g. include server-side decorations.

There is a unique instance of this class, created within LCompositor::createObjectRequest(), which can be accessed globally via CZ::imageCaptureManager().

To disable these protocols, remove their globals from LCompositor::createGlobalsRequest().

◆ sessionRequest()

virtual void sessionRequest ( LImageCaptureSession * session)
virtual

A client wants to start capturing.

The session is pending: no frames are captured until LImageCaptureSession::accept() is called, now or later (e.g. after asking the user). Call LImageCaptureSession::stop() to deny it.

Default implementation

void LImageCaptureManager::sessionRequest(LImageCaptureSession *session)
{
/* Accept every session right away. To ask the user first, keep the session
* (e.g. in a CZWeak) and call accept() or stop() once answered. */
session->accept();
}
